# Brand source library

The files in this directory are source/reference assets supplied for the Unite Recognition project.
They are not loaded automatically by the Web TV or Android TV player.

## Approved for Unite Group usage

- `unite-group-wordmark-original.png`: official transparent wordmark source.
- `unite-group-mark-black.png`: official mark on an opaque black square.
- `mascot-unite-group-suit-black.png`: square mascot, black suit.
- `mascot-unite-group-suit-white.png`: square mascot, white suit.
- `mascot-unite-group-suit-red.png`: square mascot, red suit.
- `mascot-unite-group-wide.png`: wide 16:9 mascot source.
- `reference-thong-soai-header.png`: visual reference only; text remains HTML/CSS for Full HD clarity.

## Reference only

- `mascot-un1te-one-female.png`
- `mascot-un1te-one-male.png`

The two files above contain `UN1TE ONE` branding, so they must not be published as
official `UNITE GROUP` media without explicit approval or corrected artwork.

Mascots must not be assigned as an employee's real avatar. Before publishing them to
the nine TV players, create optimized WebP renditions and serve them through Supabase
Storage/media manifests rather than bundling every full-resolution source into the APK.
